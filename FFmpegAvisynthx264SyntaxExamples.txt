FFmpeg + AviSynth+ + x264 examples
===================================

These examples assume that autobuildffavs.sh completed successfully and that
`template.avs` has been adjusted for your source.

The commands are examples, not universal encoding recommendations. Verify the
field order, crop, resize, frame rate, CRF/bitrate, and x264 tuning for each
source.


1. Demux a source for AviSynth processing
-----------------------------------------

Example: one H.264 video stream and one AC-3 audio stream from a Blu-ray REMUX.

ffmpeg -i SOURCE.mkv \
  -map 0:v:0 -c:v copy input.mkv \
  -map 0:a:0 -c:a copy audio.ac3

`input.mkv` can then be opened from `template.avs` with FFMS2.


2. Preview and inspect the AviSynth output
------------------------------------------

Install mpv if needed:

sudo apt install mpv

Preview:

mpv template.avs

Inspect stream information:

ffprobe -hide_banner template.avs

For test encodes, keep a short `Trim()` in `template.avs`. Remove or comment out
the Trim when you are ready to encode the full source.


3. CRF encode with libx264
--------------------------

A common starting point for visually transparent testing is CRF 18, but there
is no single correct CRF for every source. Compare representative frames and
adjust for the quality/size result you want.

Example based on the original project settings:

ffmpeg -i template.avs \
  -map 0:v:0 \
  -c:v libx264 \
  -crf 18 \
  -preset veryslow \
  -profile:v high \
  -level:v 4.1 \
  -pix_fmt yuv420p \
  -x264-params "aq-mode=1:deblock=-3,-3:aq-strength=0.80:psy-rd=0.95,0.00:dct-decimate=0:mbtree=0:fast-pskip=0" \
  -an \
  encode.mkv

FFmpeg supports both `-x264opts` and `-x264-params`; this project uses
`-x264-params` for the x264-specific key=value list and normal FFmpeg options
such as `-crf`, `-preset`, `-profile:v`, and `-level:v` where possible.

The x264 values above are examples. Do not copy them blindly to every source.


4. CRF versus two-pass bitrate encoding
----------------------------------------

CRF and two-pass encoding solve different problems:

- CRF targets a chosen quality level and lets bitrate/file size vary.
- Two-pass encoding targets an average bitrate/file size more predictably.

You do not need to run a two-pass encode before using CRF. Use two-pass when a
specific average bitrate or output size matters.

Example two-pass video encode targeting 5000 kbit/s:

Pass 1:

ffmpeg -i template.avs \
  -map 0:v:0 \
  -c:v libx264 \
  -b:v 5000k \
  -preset veryslow \
  -pass 1 \
  -passlogfile x264-2pass \
  -an \
  -f null /dev/null

Pass 2:

ffmpeg -i template.avs \
  -map 0:v:0 \
  -c:v libx264 \
  -b:v 5000k \
  -preset veryslow \
  -pass 2 \
  -passlogfile x264-2pass \
  -an \
  encode.mkv

Afterward, the x264-2pass log files can be removed if you no longer need them.


5. Mux the encoded video with the original audio
------------------------------------------------

ffmpeg -i encode.mkv -i audio.ac3 \
  -map 0:v:0 -map 1:a:0 \
  -c copy \
  finish.mkv


6. Optional subtitle and track metadata
---------------------------------------

Example with one external English SRT subtitle:

ffmpeg -i encode.mkv -i audio.ac3 -i subtitle.srt \
  -map 0:v:0 -map 1:a:0 -map 2:0 \
  -c copy \
  -metadata:s:v:0 title="Title of The Movie" \
  -metadata:s:a:0 language=eng \
  -metadata:s:a:0 title="English Audio" \
  -metadata:s:s:0 language=eng \
  -metadata:s:s:0 title="English SubRip" \
  finish.mkv


7. Optional chapters
--------------------

The repository includes `chapters.txt` in FFmetadata format. Edit its chapter
start/end times and titles for your source, then mux it as a metadata input:

ffmpeg -i encode.mkv -i audio.ac3 -i subtitle.srt -i chapters.txt \
  -map 0:v:0 -map 1:a:0 -map 2:0 \
  -map_metadata 3 -map_chapters 3 \
  -c copy \
  -metadata:s:v:0 title="Title of The Movie" \
  -metadata:s:a:0 language=eng \
  -metadata:s:a:0 title="English Audio" \
  -metadata:s:s:0 language=eng \
  -metadata:s:s:0 title="English SubRip" \
  finish.mkv


8. Inspect the finished file
----------------------------

ffprobe -hide_banner finish.mkv

Check the video, audio, subtitle, metadata, and chapter streams before deleting
any source or intermediate files.
